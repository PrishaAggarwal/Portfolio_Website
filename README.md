# Personal Portfolio Website

Welcome to my personal portfolio website! This project showcases my technical skills, projects, and development journey as a Computer Engineering student at Thapar Institute of Engineering & Technology.

🌐 **Live Website:** https://prisha-aggarwal-portfolio.netlify.app/

## About the Project

I built this portfolio website from scratch to create a central place to showcase my background, technical skills, and projects.

The project helped me strengthen my frontend development skills and explore website styling, interactive elements, and user experience.

## Technologies Used

* **HTML5** — Structuring the website content.
* **CSS3** — Styling, layouts, and visual design.
* **JavaScript** — Adding interactive functionality.

## Features

* Personal introduction and background.
* Technical skills and project showcase.
* Information about my development journey.
* Professional portfolio presentation.
* Contact and profile links.

## Getting Started

To run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/PrishaAggarwal/Portfolio_Website.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser, or use a local development server.

## Deployment

The website is hosted on Netlify.

Visit the live version here:
